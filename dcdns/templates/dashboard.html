Try a lookup

Every registry node also answers DNS on its own port. The client-facing resolver on 127.0.0.1:5353 asks all three and returns an answer only when a majority agrees. Try python -m dcdns.dig techfest.cs.test --all.

What you are looking at

Three registry nodes replicate a signed, ordered operation log. Writes are acknowledged only after a majority stores them. Each node independently serves DNS from the committed state it holds, so there is no central DNS server to trust: a client-facing quorum resolver accepts an answer only when 2 of 3 nodes agree. Revoked names stop resolving everywhere.
